# Demo video

Scripts that record the player demo video: a scripted walk through the log, with captions, synthesised fantasy music and click/typing sounds. No voice-over.

**Nothing touches the real database.** `record.mjs` answers every Supabase request inside the browser (auth, tables, RPCs and the realtime socket) with made-up quests and players. Unknown Supabase requests are blocked, not passed through.

The music and sound effects are generated by `mix.py` (no samples), so there are no licensing questions.

## Files

| File | Does |
|---|---|
| `record.mjs` | Drives Edge (headless, 1920×1080) through the demo with Playwright and saves screencast frames plus a log of clicks and keystrokes to `out/` |
| `assemble.py` | Turns the frames into a silent 30 fps video (`out/silent.mp4`) |
| `mix.py` | Synthesises the music and sound effects timed to the log, then muxes the final MP4 |

## Making the video

Needs Node, Python 3 and Microsoft Edge (Playwright uses the installed Edge, so no browser download). Run from PowerShell.

1. Build and serve the app on port 4173, from `app/`:

   ```bash
   npm run build --script-shell=cmd.exe
   npx vite preview --port 4173 --strictPort
   ```

2. In another terminal, from `tools/demo/`, install once:

   ```bash
   npm install
   python -m venv venv
   .\venv\Scripts\python -m pip install -r requirements.txt
   ```

3. Record, assemble and mix:

   ```bash
   node record.mjs
   .\venv\Scripts\python assemble.py
   .\venv\Scripts\python mix.py ..\..\demo\dungeon-quest-log-demo.mp4
   ```

The video lands in `demo/` at the repo root, which is git-ignored. The ffmpeg used comes from the `imageio-ffmpeg` package.

## Changing the demo

- The storyboard (captions, clicks, typed text, live changes by "other players") is the section `// ── The demo` in `record.mjs`. The fake quests are the `seed(...)` calls near the top.
- Selectors follow the app's labels (plan 9.8). If a label or class changes, the script stops with a Playwright timeout naming the element.
- The date field types day/month/year, because Edge uses the Windows date format.
- To check a take without watching it all, make contact sheets from the silent video, for example:

  ```bash
  ffmpeg -i out/silent.mp4 -vf "fps=1/6,scale=960:-1,tile=3x3" sheet%02d.png
  ```
